# Chrome Web Store Listing Draft

## Name

WebMCP Capability Forge

## Short description

Teach, discover, verify, and reuse browser workflows as human-reviewed WebMCP tools.

## Category

Productivity

## Detailed description

WebMCP Capability Forge helps people and AI agents turn browser workflows into reusable WebMCP tools.

Choose how to learn:

- Demonstrate a workflow in Manual mode.
- Let the agent inspect and explore through bounded tools in Automatic mode.
- Combine human and agent evidence in Hybrid mode.

Before activation, review the exact website scope, inputs, targets, actions, route changes, provenance, risk, and expected effects. Safe workflows receive replay verification. Consequential actions remain guarded. Stale targets produce structured evidence for a reviewed repair.

Capability definitions and evidence remain on your device in Chrome local storage. The extension sends no telemetry or workflow data to the publisher.
