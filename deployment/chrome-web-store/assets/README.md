# Chrome Web Store Asset Requirements

Create final media only after the production extension UI and product identity are stable.

## Required icon

- Format: PNG
- Canvas: 128x128 pixels
- Artwork: about 96x96 pixels for a square mark, centered with transparent padding
- Appearance: front-facing, readable on light and dark surfaces, no screenshot or embedded UI
- Package requirement: include the 128x128 icon in the extension ZIP and reference it from the manifest

## Required screenshots

- Format: PNG or JPEG
- Size: 1280x800 pixels preferred; 640x400 is accepted
- Count: one required, five preferred
- Composition: square corners, full bleed, current production extension only
- Planned sequence: site enablement, Manual trace, Hybrid provenance, reviewed capability, repair evidence

## Required small promo tile

- Format: PNG or JPEG
- Size: 440x280 pixels
- Use product identity rather than a screenshot
- Keep text sparse and readable at half size

## Optional marquee

- Format: PNG or JPEG
- Size: 1400x560 pixels
- Use only if the final brand image remains clear without an endorsement claim

## Prohibited material

- No mock screenshots
- No Google, Chrome, OpenAI, or challenge endorsement cues
- No rankings, awards, install counts, testimonials, or performance claims without evidence
- No dense text, clipped interface, browser notifications, private data, or unrelated website branding
