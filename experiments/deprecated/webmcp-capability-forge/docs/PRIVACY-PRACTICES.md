# Chrome Web Store Privacy Practices Draft

## Single purpose

Teach, discover, verify, and reuse browser workflows as human-reviewed WebMCP tools.

## Data categories handled locally

- Website content: yes, limited to visible-control metadata and bounded observations needed for workflows.
- Form data: yes, limited to non-sensitive workflow inputs. Sensitive targets are blocked.
- Web browsing activity: yes, limited to enabled origin/path and route checkpoints.
- User activity: yes, limited to demonstrated and agent-performed workflow actions.
- Authentication, financial, health, personal communications, precise location: no intended collection.

## Transmission and sharing

- Remote telemetry: none.
- Publisher backend: none.
- Sale or advertising use: none.
- Third-party sharing: none for extension workflow data.
- Website infrastructure: Google Firebase Hosting may process standard website request/security logs.

## Certifications

- Data use is limited to the disclosed single purpose.
- No data is used for personalized advertising or credit decisions.
- Humans do not review user workflow data because it is not transmitted to the publisher.
- The website policy, Store answers, manifest, and release behavior must be reconciled before submission.
