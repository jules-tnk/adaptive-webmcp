# Privacy Policy

Effective August 29, 2026

Kibalo Jules Tinaka publishes WebMCP Capability Forge as an individual from Morocco. Contact: `julestnk.dev@gmail.com`.

The extension processes the enabled page origin and path, visible-control metadata, bounded observations, interactions, non-sensitive workflow inputs, capability definitions, selector evidence, revisions, verification, health, and bounded failures. It stores that information in `chrome.storage.local` on the user's device.

The extension is designed to block passwords, payment fields, authentication codes, file inputs, and hidden inputs. It does not intentionally store cookies, complete page snapshots, complete conversations, or browser history. It sends no workflow data or telemetry to the publisher, sells no data, serves no advertising, and has no backend, account, cloud sync, or remote model API.

The website uses no analytics, advertising, tracking cookies, accounts, telemetry, forms, or mailing lists. Classic Google Firebase Hosting serves the website; Firebase Analytics and every other Firebase product are disabled. Firebase Hosting may process standard request and security logs. Firebase's current retention and subprocessors must be reconfirmed before publication.

Users can disable site access, delete tools, clear local extension data, export approved definitions, or uninstall the extension. Information received through Chrome APIs is used only for the disclosed single purpose and is intended to comply with the Chrome Web Store User Data Policy, including Limited Use requirements.

The product is not directed to children under 13. Material policy changes will appear on the official website and in Store disclosures before changed handling begins.

Canonical policy: `https://webmcp-forge.jules-tnk.com/privacy`
