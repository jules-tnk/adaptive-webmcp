# Chrome Web Store Submission Checklist

## Publisher and public URLs

- [x] Developer registration fee paid
- [x] Publisher name configured
- [x] Contact email verified
- [ ] Trader verification resolved
- [x] Firebase fallback homepage deployed
- [x] Custom-domain certificate connected
- [x] Homepage, Privacy, and Support verified on the custom domain
- [x] Search Console ownership available to the publisher account

## Package and runtime audit

- [ ] Final manifest reconciliation
- [ ] Production ZIP
- [ ] Manifest is at the ZIP root
- [ ] Production version is higher than any previous upload
- [ ] No remote code
- [ ] Required permissions match implemented features
- [ ] Optional host permissions remain optional
- [ ] Sensitive target blocking verified
- [ ] Data practices match the privacy policy and dashboard

## Store materials

- [x] English listing draft
- [x] Single-purpose draft
- [x] Permission justifications draft
- [x] Data disclosure matrix
- [x] Prominent disclosure copy
- [x] Privacy policy draft
- [x] Reviewer instructions draft
- [x] Asset requirements documented
- [ ] 128x128 production icon
- [ ] Actual screenshots
- [ ] Required 440x280 small promo tile

## Evidence

- [ ] Automated extension evidence
- [ ] Native WebMCP evidence
- [ ] Manual learning verified
- [ ] Automatic learning verified
- [ ] Hybrid learning verified
- [ ] Reload restoration verified
- [ ] Risk confirmation verified
- [ ] Stale-target detection and reviewed repair verified

## Release

- [ ] Store item creation
- [ ] Package upload
- [ ] Dashboard privacy answers completed
- [ ] Distribution set to free, public, all regions, deferred publishing
- [ ] Submit for Review
- [ ] Public release

The publisher must personally approve Submit for Review and public release.
