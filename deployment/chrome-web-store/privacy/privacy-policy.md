# WebMCP Capability Forge Privacy Policy

Effective: 29 August 2026

This policy describes the intended first Chrome Web Store release of WebMCP Capability Forge. Reconcile it with the production manifest and extension behavior before submission. The public policy is hosted at https://webmcp-forge.jules-tnk.com/privacy.

## Information processed

On a site the user chooses to enable, Capability Forge may process the current website origin and path, visible controls and bounded page content, workflow interactions, non-sensitive form examples, extracted results, capability definitions, revisions, verification records, and bounded execution evidence.

Capability Forge uses this information to learn, review, verify, run, and repair workflows requested by the user. It does not use the information for advertising, profiling, or an unrelated purpose.

## AI agent disclosure

A WebMCP-aware AI agent selected by the user may receive bounded page observations, workflow traces, tool definitions, extracted results, and failure evidence needed to complete the user's request. The agent provider may process that information under its own terms and privacy policy. Capability Forge does not choose the provider.

## Local storage and retention

Capability Forge stores approved tools, bounded traces, revisions, verification records, and failure summaries in Chrome local storage on the user's device. Jules TNK operates no server that receives this workflow data. Users can delete saved tools through the extension. Removing the extension removes its extension storage according to Chrome's behavior.

## Sensitive targets

The extension design blocks passwords, payment fields, authentication codes, file inputs, and other sensitive targets. It does not intend to record or store those values. A person must review new or repaired workflows, and consequential actions require confirmation.

## Browser permissions

Capability Forge uses browser permissions to access the current tab after a direct user action, inject packaged recorder and runtime code into an enabled site, store approved local workflows, maintain active-tab route state, and show the side-panel interface. Optional site access applies only after the user enables a host.

## Developer access and disclosure

Jules TNK does not receive page content, workflow traces, or learned-tool data. Capability Forge does not sell workflow data or transfer it for advertising. The extension may disclose bounded information to the AI agent the user connects because that transfer provides the extension's workflow-learning and reuse features.

## Chrome Web Store Limited Use

WebMCP Capability Forge's use of information received from browser permissions will comply with the Chrome Web Store User Data Policy, including the Limited Use requirements. Jules TNK will use that information only to provide or improve the extension's disclosed workflow-learning and reuse features. Jules TNK will not sell the data, use it for personalized advertising, or allow human access except when the user provides specific consent for support, when security requires it, or when law requires it.

## Changes and contact

Jules TNK will update the public policy and required in-extension disclosures before changing data practices. Privacy questions can be sent to julestnk.dev@gmail.com. Do not send passwords, payment information, authentication codes, private page content, or identity documents.
